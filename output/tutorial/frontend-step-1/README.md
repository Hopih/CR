# Подготовка frontend: учебные материалы

Основной туториал находится в `HttpListenerStepByStep_Frontend_Step_1_Tutorial.md`.
Обновлённая PDF-версия: `output/pdf/HttpListenerStepByStep_Frontend_And_JS_Modules_Tutorial.pdf` от корня репозитория.

Папка `examples` содержит первый проход с одним script.js. `examples-modules` содержит итоговый вариант с ES-модулями. Чтобы проверить их на существующем сервере, сохраните свою рабочую копию и замените `index.html`, `styles.css`, `script.js` в `HttpListenerStepByStep/public`. Для модульного варианта перенесите содержимое examples-modules целиком в public, включая js, и замените в .csproj шаблон public\*.* на public\**\*.*. Не подключайте script.js вместе с main.js. SVG-иконки совпадают с исходными. Запустите `dotnet run` из каталога `HttpListenerStepByStep`, затем откройте `http://localhost:5000/`.

Модель хранится в памяти; перезагрузка удаляет стикеры. ES-модули разобраны в разделе 16. PostgreSQL и сохранение через API относятся к следующим занятиям. Локальные UUID примера не являются серверными идентификаторами сохранённых объектов.

Проверено в Microsoft Edge в автоматическом режиме: создание с цитатой; буквальное отображение HTML-подобного текста; многократное редактирование без новых ручек; Ctrl+Enter, Escape, пустой текст; drag относительно доски; прокрутка и граница; resize с минимумом 80; отсутствие изменения координат при resize; callback после завершения; запасной текст при HTTP 500; размеры окна; исчезновение стикеров при reload. JavaScript-фрагменты туториала совпадают с проверенным полным script.js.

Проверка использовала отдельный локальный сервер с тестовым ответом `/quote/random`. Работа внешнего сервиса цитат и будущего PostgreSQL API в эту проверку не входила. Файлы приложения при подготовке урока не изменялись.

Архив включает оба варианта в отдельных папках: single-file/public и modules/public. Используйте один вариант за раз.

Дополнительно проверен модульный вариант: семь импортов возвращают 200 с корректным MIME; функции не становятся глобальными; редактор, drag, resize, прокрутка и запасной текст цитаты работают без ошибок в Console. Все полные модульные листинги в туториале совпадают с проверенными файлами.
