# Заготовки для контрольной работы

Три независимых консольных приложения на **.NET 10**, без NuGet-пакетов,
базы данных и авторизации. Откройте `ControlWork.slnx` в IDE с поддержкой
.NET 10 либо запускайте проекты из терминала. Требуется .NET SDK 10.

Команды ниже выполняются из папки `ControlWork`.

## Курсы валют: CurrencyWeb

```powershell
dotnet run --project CurrencyWeb
```

Откройте http://localhost:8080/ . Остановка — Ctrl+C.
Статические файлы ищутся относительно собранного приложения, поэтому запуск
не зависит от текущей папки терминала.

Сайт показывает код, название, номинал и курс каждой валюты к рублю.
Курс указан **за номинал**, например за 100 единиц, а не обязательно за одну.
Дата в таблице — дата действия курсов из источника.

Путь запроса: `public/app.js` → `GET /api/rates` → `WebServer.cs` →
`RatesService.cs` → https://www.cbr-xml-daily.ru/daily_json.js .
Файл с расширением `.js` содержит JSON. `System.Net.Http.Json` разбирает его
напрямую. Это сторонний сервис с данными ЦБ РФ, а не официальный API ЦБ.

Ответ нашего сервера (условный пример):

```json
{
  "date": "2026-10-27T11:30:00+03:00",
  "currencies": [
    { "charCode": "USD", "name": "Доллар США", "nominal": 1, "value": 80.1234 }
  ]
}
```

HTTP: успешный запрос — 200; неизвестный путь — 404; метод кроме GET — 405;
ошибка внешнего API — 502. Ошибки возвращаются как `{ "error": "..." }`.
Маршруты статических файлов заданы явно в `WebServer.cs`.

Кеш в памяти общий для посетителей одного процесса и действует 5 минут.
Неудачные загрузки повторяются не чаще раза в минуту. При ошибке обновления
сервер возвращает ошибку, а страница сохраняет ранее показанную таблицу.
Кнопка «Обновить» повторно запрашивает наш сервер, но не сбрасывает кеш.
После перезапуска приложения кеш пуст.

Условия источника: https://www.cbr-xml-daily.ru/ — ссылка на сервис,
не более 1 запроса/секунду, 30/минуту с IP и 10000/сутки.
**Кеши разных экземпляров сервера независимы.** Если вся аудитория выходит
через один IP, одновременный первый запуск множества экземпляров может
превысить лимит. Перед КР проверить доступ без VPN из сети аудитории и
разнести первые запуски по времени с учётом этих лимитов.

Файлы для расширения: `RatesService.cs` — внешний API и модели;
`WebServer.cs` — HTTP-маршруты; `public/` — HTML, CSS и JavaScript.
Конвертация, поиск, сортировка, предыдущий курс и выбор даты пока не реализованы.

## Угадай число: NumberGuessServer и NumberGuessClient

В первом терминале:

```powershell
dotnet run --project NumberGuessServer
```

Во втором:

```powershell
dotnet run --project NumberGuessClient
```

Введите `start`, затем числа от 1 до 100. Подсказки сообщают, больше или меньше
загаданное число. `quit` завершает подключение. После победы нужна новая
команда `start`. Её можно отправить и в середине игры для перезапуска.
Можно запустить несколько клиентов: состояние каждого независимо.

Оба приложения используют `System.Net.Sockets.Socket`, TCP и адрес
`127.0.0.1:5050`. Веб-сервер и игра запускаются независимо.
После отключения клиента его игра теряется. Сервер завершает работу по Ctrl+C.

### Протокол

Текст UTF-8 без BOM. Каждая команда и каждый ответ заканчиваются `\n`.
Сервер принимает также `\r\n`. На одну команду приходит ровно один ответ.
Приветственного сообщения при подключении нет. Регистр команды не важен.
TCP может дробить и объединять передачи: граница сообщения определяется
переводом строки, а не одним вызовом Receive. В обоих приложениях обмен
выполняется напрямую через `Socket.SendAsync` и `Socket.ReceiveAsync`, без
потоков, декораторов и адаптеров над Socket. Приём накапливает байты до `\n`
и только затем декодирует UTF-8, а отправка учитывает частичную передачу.
Максимальная длина строки — 1024 байта до `\n`, включая `\r`, если он есть.
При отключении незаконченная строка отбрасывается.

| Команда | Ответ | Значение |
| --- | --- | --- |
| `START` | `OK` | Начать или перезапустить игру, число от 1 до 100 включительно |
| `GUESS 42` | `GREATER` | Загаданное число больше 42 |
| `GUESS 42` | `LESS` | Загаданное число меньше 42 |
| `GUESS 42` | `WIN` | Число угадано, раунд завершён |
| `QUIT` | `BYE` | Сервер отправляет ответ и закрывает подключение |

| Ошибка | Причина |
| --- | --- |
| `ERROR NOT_STARTED` | Корректная попытка до START или после победы |
| `ERROR INVALID_NUMBER` | Не целое число, вне диапазона 1–100 или неверное число аргументов GUESS |
| `ERROR INVALID_ARGUMENTS` | Лишние аргументы START или QUIT |
| `ERROR UNKNOWN_COMMAND` | Пустая или неизвестная команда |
| `ERROR LINE_TOO_LONG` | Строка длиннее 1024 байт; после ответа сервер закрывает подключение |

Сначала проверяется формат команды, затем состояние игры. После ошибки
соединение остаётся открытым, кроме `LINE_TOO_LONG`. В консольном клиенте можно вводить как число,
так и полную команду `GUESS 42`.

Файлы для расширения: `NumberGuessServer/GameSession.cs` — правила и команды;
`NumberGuessServer/Program.cs` — подключения и обмен;
`NumberGuessClient/Program.cs` — ввод, отправка команд и вывод ответов.
STATUS, GIVEUP, счётчик попыток и ограничение попыток пока не реализованы.

## Проверка сборки

```powershell
dotnet build ControlWork.slnx
```

Это отдельное решение: существующие учебные проекты репозитория не требуются.

Дополнительная проверка с Python 3 (без сторонних библиотек):

```powershell
python check_starters.py
```

Запускать после сборки, когда порты 8080 и 5050 свободны. Скрипт временно
запускает серверы и проверяет маршруты, реальные курсы и кеш, TCP-протокол,
независимость игр, победу и работу консольного клиента. Нужен интернет.
По завершении запущенные им серверы останавливаются.
